Design decisions

Decision Rationale Tradeoff Evidence
Synchronize channels before advancing time. Keeps simulated callbacks on a shared historical clock. Replay waits for participating producer processing rather than evaluating all trades as a vectorized portfolio kernel. TimeUpdater.start (L34)

Workflow

Host historical replay

Host integration supplies trading decisions, orders and final analytics; this toolkit is not a standalone broker engine.

  W2["Push current simulated timestamp."]
  W1 --> W2
  W3["Complete synchronized callbacks then advance replay time."]
  W2 --> W3
  1. Host supplies exchange/matrix IDs and historical data files.. Backtesting.initialize (L45) / Backtesting.create_importers (L97)

Strengths and limits

Strengths

  • Reusable importer mapping and preloaded candle managers avoid forcing each replay consumer to re-read files. Backtesting.create_importers (L97) / BacktestData.get_preloaded_candles_manager (L23)

Limitations

  • Accurate price-timeframe mode requires importer full-timeframe candle history; missing coverage returns false. Backtesting.use_accurate_price_time_frame (L65)
